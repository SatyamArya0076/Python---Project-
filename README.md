## 🧟 About the Project

Zombie Aim: Last Stand is a Python-based desktop game created as a major academic project.

The player must survive in an arena while zombies approach from different directions. The player can move around, aim with the mouse, select weapons, and shoot zombies to increase their score.

The game demonstrates fundamental Python programming concepts, including object-oriented programming, event handling, collision detection, randomization, and graphical user interface development.

## ✨ Features

- 🎮 Interactive desktop game interface.
- 🧍 Player movement using keyboard controls.
- 🖱️ Mouse-based aiming and shooting.
- 🔫 Multiple weapons: Pistol, Shotgun, and Rifle.
- 🧟 Zombies spawn and chase the player.
- ❤️ Player health system.
- 🏆 Score tracking.
- 📈 Increasing difficulty as the score grows.
- 🔄 New Game option.
- 🔊 Optional sound effects on supported Windows systems.

## 💻 Installation

### Prerequisites

- Python 3 installed on your computer.
- Tkinter available in your Python installation.
- A code editor such as VS Code (optional).

### Step 1: Clone the Repository

Open your terminal and run:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual repository URL.

### Step 2: Open the Project Folder

```bash
cd python-major-prject--main
```

### Step 3: Run the Game

```bash
python SHOOTING.PY
```

On Windows, you can also try:

```powershell
py SHOOTING.PY
```

**Note:** The game uses Python's standard library, so no third-party package installation should normally be required.

## 🕹️ How to Play

1. Start the game.
2. Enter a player name if prompted.
3. Use the keyboard to move around the arena.
4. Move your mouse to aim at zombies.
5. Click inside the game arena to shoot.
6. Select different weapons to change your shooting strategy.
7. Avoid zombie attacks and defeat as many zombies as possible.
8. Start a new round after the game ends.

## ⌨️ Game Controls

| Control | Action |
|---|---|
| W / A / S / D | Move the player |
| Arrow Keys | Move the player |
| Mouse Movement | Aim |
| Mouse Click | Shoot |

## 🔫 Weapons

| Weapon | Damage per Pellet | Description |
|---|---:|---|
| Pistol | 34 | Balanced damage and firing speed |
| Shotgun | 22 | Fires multiple pellets |
| Rifle | 18 | Fast firing with lower damage per shot |

*Weapon performance depends on aim, firing cooldown, and successful hits.*

## ❤️ Game Rules

- The player starts with 100 health.
- Each zombie bite reduces player health by 10.
- Each defeated zombie adds 1 point to the score.
- Zombies have 70 health in the current implementation.
- Zombie spawning becomes more frequent as the score increases.
- The game ends when the player's health reaches zero.
